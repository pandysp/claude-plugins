# manage-agents

A Claude Code, Codex and Pi plugin for running a team of agent sessions in [agent-manager](https://github.com/YoanWai/agent-manager) the way a chief of staff runs an organisation.

## Why

With many agent sessions running, the scarce resource is the user's attention. This skill gives the sessions a hierarchy: the user talks to one top session, which hands work to one manager per group. Managers brief, track and follow up on the sessions in their group, and the sessions do the work. Every level runs the same loop: prepare, delegate, track, follow up.

## Usage

- Claude Code: `/manage-agents`
- Codex: `$manage-agents`

Or ask a session to be your assistant, set up group managers, or delegate work to them.

## Requirements

[agent-manager](https://github.com/YoanWai/agent-manager) (`brew install agent-manager`).
