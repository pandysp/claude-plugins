# excalidraw

Draws diagrams and sketches with Excalidraw in your Obsidian vault. The agent writes a short drawing script, runs it inside Obsidian, looks at a screenshot and fixes what is wrong.

## Usage

- Claude Code: `/excalidraw`
- Codex: `$excalidraw`
- Pi: `/skill:excalidraw`

Or just ask: "Draw a process diagram of our release steps." / "Sketch a tetrahedron."

## Requirements

- Obsidian running, with the vault open
- The Excalidraw plugin installed
- The Obsidian command line tool (`obsidian`) turned on
- Node
